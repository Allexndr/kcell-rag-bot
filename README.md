# 🤖 Kcell RAG Bot

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Telegram Bot](https://img.shields.io/badge/Telegram-Bot-blue.svg)](https://t.me/)

**Интеллектуальная система поиска и ответов на вопросы по корпоративным документам Kcell**

Система использует современные технологии ИИ для быстрого и точного поиска информации в обширной базе корпоративных документов компании Kcell. Основана на Retrieval-Augmented Generation (RAG) архитектуре с локальными моделями ИИ.

## 🚀 Ключевые возможности

- **Интеллектуальный поиск** по 300+ документам (PDF, DOCX, XLSX, PPTX)
- **Локальная обработка** без передачи данных в облако
- **Многоязычная поддержка** (Русский, Казахский, Английский)
- **Telegram интерфейс** для удобного взаимодействия
- **Автоматическое обучение** на обратной связи пользователей
- **Модульная архитектура** для легкого расширения

## 🏗️ Архитектура системы

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Telegram Bot  │    │   RAG Engine    │    │   Document DB   │
│   (main.py)     │◄──►│ (rag_engine_    │◄──►│   (Chroma DB)   │
│                 │    │    local.py)    │    │                 │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         │                       │                       │
         ▼                       ▼                       ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   User Queries  │    │   Ollama LLM    │    │   Document      │
│                 │    │   (llama3.1:8b) │    │   Ingestion     │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### Компоненты:

- **Telegram Bot** - пользовательский интерфейс
- **RAG Engine** - обработка запросов и генерация ответов
- **Chroma DB** - векторная база данных
- **Ollama** - локальная языковая модель
- **Document Ingestion** - индексация документов

## 📋 Системные требования

### Минимальные:
- **ОС**: macOS, Linux, Windows
- **RAM**: 8 GB
- **Диск**: 20 GB свободного места
- **Процессор**: 4-core CPU

### Рекомендуемые:
- **RAM**: 16 GB+
- **Диск**: SSD с 25 GB свободного места
- **Процессор**: 6-core CPU или выше

## 🛠️ Установка и запуск

### 1. Предварительные требования

```bash
# Установка Ollama
brew install ollama  # для macOS
# или следуйте инструкциям на https://ollama.ai/

# Запуск Ollama сервера
ollama serve

# Скачивание модели
ollama pull llama3.1:8b
```

### 2. Установка зависимостей

```bash
git clone https://github.com/Allexndr/kcellbot.git
cd kcellbot
pip install -r requirements.txt
```

### 3. Конфигурация

Создайте `.env` файл на основе `.env.example`:

```bash
cp .env.example .env
# Отредактируйте TELEGRAM_BOT_TOKEN в .env файле
```

### 4. Индексация документов

```bash
python3 ingest_file.py
```

### 5. Запуск бота

```bash
python3 main.py
```

## 📱 Использование

### Через Telegram Bot

1. **Запуск**: `/start`
2. **Вопросы**: просто напишите вопрос о документах
3. **Загрузка файлов**: отправьте документ боту для индексации
4. **Очистка памяти**: `/clear`
5. **Статистика**: `/stats` (только для администраторов)

### Примеры запросов

```
Как подключить револьверный пакет?
Какие тарифы действуют в 2024 году?
Что такое ВАТС?
```
