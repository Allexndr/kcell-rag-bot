# 📋 Changelog - Kcell RAG Bot

Все значимые изменения в проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-19

### 🎉 Добавлено (Added)
- **Полная система RAG** - Retrieval-Augmented Generation для интеллектуального поиска
- **Telegram Bot интерфейс** - удобный чат-бот для взаимодействия
- **Многоязычная поддержка** - русский, казахский, английский языки
- **Векторная база данных** - Chroma DB с 2848 векторными представлениями
- **Локальная LLM** - Ollama с моделью llama3.1:8b (4.9GB)
- **Автоматическая индексация** - поддержка PDF, DOCX, XLSX, PPTX, TXT, RTF
- **Система безопасности** - многоязычный фильтр опасного контента
- **Обратная связь пользователей** - кнопки лайк/дизлайк с аналитикой
- **Память разговоров** - контекст предыдущих сообщений
- **Персонализация** - адаптация под стиль пользователя
- **Авто-обновление знаний** - мониторинг изменений в документах
- **Гибридный поиск** - векторный + TF-IDF + BM25
- **Подробная аналитика** - процент вклада каждого документа в ответ

### 🔧 Изменено (Changed)
- **Модульная архитектура** - разделение на src/core, src/security, src/personalization, src/auto_update
- **Улучшенная индексация** - OCR для сканированных PDF, обработка таблиц
- **Оптимизация производительности** - кэширование, LRU cache
- **Чанкинг текста** - 4000 символов с перекрытием 500

### 🐛 Исправлено (Fixed)
- **Фильтр безопасности** - теперь блокирует опасные запросы на всех языках
- **Обработка ошибок** - graceful degradation при недоступности компонентов
- **UTF-8 кодировка** - правильная обработка кириллицы

### 📚 Документация (Documentation)
- **Полная техническая документация** - Kcell_RAG_Bot_Full_Documentation.txt
- **README для GitHub** - установка, использование, архитектура
- **CONTRIBUTING.md** - руководство по вкладу в проект
- **CHANGELOG.md** - история изменений
- **GitHub Issue Templates** - шаблоны для баг-репортов и фич-реквестов

### 🏗️ Технические детали (Technical)
- **Python 3.8+** - минимальная версия
- **16GB RAM** - рекомендуемые системные требования
- **2850 документов** - размер базы знаний
- **4.9GB модель** - размер Ollama модели
- **902MB проект** - размер репозитория без модели

## 📝 Формат версий

- **MAJOR.MINOR.PATCH** - согласно Semantic Versioning
- **MAJOR** - breaking changes
- **MINOR** - новые функции (backward compatible)
- **PATCH** - bug fixes (backward compatible)

## 🎯 Типы изменений

- **Added** - новые функции
- **Changed** - изменения в существующих функциях
- **Deprecated** - устаревшие функции
- **Removed** - удаленные функции
- **Fixed** - исправления ошибок
- **Security** - исправления безопасности
